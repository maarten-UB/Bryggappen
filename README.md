# Bryggappen – GitHub Pages

Detta är startsidan för Bryggappen.

## Filer

- `index.html` – startsidan
- `manifest.json` – PWA-konfiguration
- `icon-192.png` – appikon
- `icon-512.png` – appikon

## Publicering

Aktivera GitHub Pages för repositoryt och välj branch `main` samt mappen `/ (root)`.

Startsidan ska ligga kvar på GitHub Pages. Knapparna öppnar respektive del av produktionsappen i Google Apps Script.

## Viktigt

Ändra inte Apps Script-URL:en i `index.html` om den befintliga `/exec`-adressen fortfarande används.
