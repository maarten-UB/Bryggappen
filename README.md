# Bryggappen – GitHub Pages PWA

Detta repo innehåller bara PWA-skalet för Bryggappen.

Filer:
- `index.html`
- `manifest.json`
- `icon-192.png`
- `icon-512.png`

## GitHub Pages
I GitHub: Settings → Pages → Build and deployment → Source: Deploy from a branch.
Välj `main` och `/ (root)` och spara.

När Pages är aktiv blir adressen:
https://maarten-ub.github.io/Bryggappen/

Öppna den adressen på mobilen och välj Chrome → Installera och skapa genväg.

Själva produktionsappen ligger fortfarande i Google Apps Script. Detta repo innehåller inga kalkylblad, lösenord eller produktionsdata.
