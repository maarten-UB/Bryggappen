
# Bryggappen – GitHub Pages PWA

Detta är PWA-skalet för Bryggappen.

Filer:
- `index.html`
- `manifest.json`
- `icon-192.png`
- `icon-512.png`

GitHub Pages:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Öppna sedan:
https://maarten-ub.github.io/Bryggappen/

GitHub-sidan använder ingen iframe. Den öppnar produktionsappen direkt i Google Apps Script.
